# No Culling

Mod cliente para Fabric (Minecraft 26.2) que apaga el **occlusion culling** del juego.
Con freecam, las cuevas y espacios bajo tierra se dibujan aunque no estén conectados por aire a la cámara.

## Instalar (jugadores)
1. Instala Fabric Loader para 26.2 y Java 25.
2. Pon `nocull-1.0.0.jar` y Fabric API en la carpeta `mods`.
3. Listo. Costo: menos FPS, porque se dibujan más chunks.
